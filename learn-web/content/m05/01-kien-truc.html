Kiến trúc ros2_control

ros2_control không phải một node — nó là một framework gồm nhiều mảnh ghép cùng chạy trong một tiến trình (controller_manager), nói chuyện với nhau qua 2 khái niệm trung tâm: command interface và state interface.

3 lớp, 3 việc khác nhau

  • Hardware Interface — lớp chạm vào phần cứng thật (hoặc Gazebo). Với Atlas, đây là plugin gz_ros2_control: nó "giả vờ" là driver động cơ, đọc/ghi trực tiếp vào mô phỏng. Khai báo bao nhiêu interface (bao nhiêu con số đọc/ghi được) là việc của <ros2_control> trong URDF (bài sau).
  • Controller Manager — vòng lặp trung tâm, chạy ở một tần số cố định (Atlas: 100Hz). Mỗi chu kỳ nó: đọc toàn bộ state interface từ hardware interface → đưa cho các controller đang active → gom command interface controller vừa ghi → gửi xuống hardware interface.
  • Controller — logic thật sự. Atlas dùng 2 controller cùng lúc: diff_drive_controller (nhận /cmd_vel, tính vận tốc từng bánh, publish /odom) và joint_state_broadcaster (chỉ đọc state interface, publish lại thành /joint_states — chính là nguồn mà robot_state_publisher đã chờ từ Module 3).

Command interface và state interface

Mỗi joint có thể khai báo nhiều interface, mỗi interface là một con số duy nhất:

LoạiChiềuÝ nghĩaAtlas dùng gì
command interfacecontroller → hardware"tôi muốn joint này làm gì"velocity — tốc độ quay mong muốn (rad/s)
state interfacehardware → controller"joint này đang thế nào"position + velocity — góc và tốc độ thật

Atlas không dùng command interface position hay effort — 2 bánh xe là continuous (Module 3, quay vô hạn), ra lệnh bằng "góc mong muốn" vô nghĩa với loại khớp này. Chỉ tốc độ mới hợp lý.

Vì sao tách controller_manager khỏi node ứng dụng

Bạn gõ ros2 topic pub /cmd_vel ... ở bài trước — đó là một node hoàn toàn độc lập, không biết gì về Gazebo hay ros2_control. Nó chỉ publish lên một topic tên /cmd_vel. diff_drive_controller subscribe đúng topic đó. Thay node phát lệnh (gõ tay → teleop_twist_keyboard ở Module 7 → Nav2 ở Module 10) không cần đổi gì ở tầng ros2_control — đúng kiểu tách lớp đã thấy xuyên suốt dự án.

Thử ngay

ros2 launch atlas_control controller.launch.py
ros2 control list_hardware_interfaces

Xem đúng 4 interface của 2 bánh: velocity command + position/velocity state cho mỗi bánh, đúng những gì bảng trên liệt kê — không hơn không kém.

ros2 control list_controllers

2 controller, cả hai ở trạng thái active (bài 5 giải thích trạng thái này đến từ đâu).
