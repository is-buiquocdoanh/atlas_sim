Đọc & so sánh 3 file cấu hình controller

3 bài trước đã trích từng mảnh. Bài này đọc hệ thống: xác nhận bằng chính diff xem 3 file nav2_params_dwb/rpp/mppi.yaml thật sự giống nhau ở đâu, khác nhau ở đâu — kỹ năng đọc config hữu ích hơn nhiều so với nhớ từng con số.

Xác nhận bằng diff thật, không chỉ tin lời kể

diff src/atlas_slam/config/nav2_params_dwb.yaml \
     src/atlas_slam/config/nav2_params_mppi.yaml

Kết quả thật: chỉ khác ở dòng comment đầu file (tên controller) và toàn bộ khối FollowPath — mọi khối còn lại (global_costmap, local_costmap, planner_server, bt_navigator, behavior_server, smoother_server, map_server) giống hệt từng ký tự. Đây là cấu trúc "1 tham số thay đổi, mọi thứ khác giữ nguyên" — đúng tinh thần so sánh khoa học của bài tập cuối module: chỉ đổi controller, mọi điều kiện khác phải y hệt.

600 vs 3000: vì sao chênh lệch chi phí tính toán lớn vậy

DWB chỉ cần mô phỏng 600 quỹ đạo NGẮN (sim_time: 1.5s); MPPI mô phỏng 3000 quỹ đạo DÀI hơn (horizon 1.75s, gần tương đương) nhưng số lượng gấp 5 lần — đúng lý do bài Local controller nói MPPI "tốn CPU nhất". Đổi lại, 3000 mẫu phủ không gian quỹ đạo rộng hơn nhiều so với lưới 20×30 cố định của DWB — ít khả năng bỏ sót 1 lối thoát mà DWB không "nhìn" tới.

9 critic của MPPI — trọng số nói lên ưu tiên gì

critics: ["ObstaclesCritic","ConstraintCritic","CostCritic","GoalCritic",

          "PathAngleCritic","PreferForwardCritic"]

ObstaclesCritic.critical_weight: 20.0     # cao nhất trong mọi trọng số đơn
PathFollowCritic.cost_weight: 9.0   # ưu tiên bám path hơn mọi path-critic khác
PathAlignCritic.cost_weight: 4.0
GoalCritic.cost_weight: 5.0

ObstaclesCritic.critical_weight: 20.0 cao vượt trội — đúng thiết kế an toàn-trước-tiên: dù các critic khác (bám path, hướng đúng) cộng dồn bao nhiêu, 1 quỹ đạo gần va chạm vẫn bị phạt nặng hơn hẳn, gần như luôn bị loại (collision_cost: 10000.0 cho quỹ đạo va chạm thật sự — comment gốc trong file: "gần như loại bỏ hoàn toàn các quỹ đạo đó khỏi lựa chọn").

Thử ngay

diff src/atlas_slam/config/nav2_params_rpp.yaml \
     src/atlas_slam/config/nav2_params_mppi.yaml

Tự chạy diff cho cặp còn lại (RPP vs MPPI) — xác nhận cùng kết luận: chỉ khối FollowPath khác nhau. Sau đó mở cả 3 file cạnh nhau, tự tìm thêm 1 tham số [CHỈNH] nào đó (comment đánh dấu "đã chỉnh tay") chưa được nhắc tới trong module — giải thích bằng lời tại sao cần chỉnh.
