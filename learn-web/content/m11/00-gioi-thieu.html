Mở nắp bt_navigator

Module 10 đã gặp bt_navigator như 1 hộp đen "điều phối" — gọi đúng thứ tự planner/controller/behavior nhưng không giải thích RA SAO. Module này mở hộp đó ra: đọc nguyên văn file XML 37 dòng thật đang quyết định hành vi robot mỗi lần bạn gửi goal, và hiểu rõ 4 "mánh" khắc phục sự cố thật robot tự làm khi kẹt.

Sau module này bạn sẽ

  • Giải thích được Behavior Tree khác state machine ở điểm cốt lõi nào — không chỉ "cây thì khác đồ thị"
  • Đọc hiểu đúng 100% cây BT XML thật Atlas đang chạy — không bỏ sót dòng nào, biết chính xác RecoveryNode/PipelineSequence/ReactiveFallback/RoundRobin làm gì
  • Kể tên đúng 4 recovery behavior thật, biết chính xác cái nào được BT mặc định gọi, cái nào nạp sẵn nhưng chưa ai dùng tới
  • Sửa được 1 file BT XML và trỏ bt_navigator dùng file mới — không cần build lại code

Vì sao module này không cần code mới

Mọi thứ trong module này đã chạy sẵn mỗi khi bạn dùng Nav2 từ Module 10 — chỉ chưa "mở nắp" xem bên trong. navigation.launch.py không hề tự viết BT riêng cho Atlas; nó dùng nguyên văn file BT mặc định của chính Nav2, cài sẵn trong gói nav2_bt_navigator khi bạn apt install ROS 2 — không phải do dự án viết ra.

Chuẩn bị

cd ~/atlas_sim
colcon build --packages-select atlas_slam
source install/setup.bash

Không cần robot/world mới — dùng lại đúng cách chạy Nav2 từ Module 10 (bringup.launch.py + navigation.launch.py).
